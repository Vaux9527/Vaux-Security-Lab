实验说明 Description

这是一个头像上传。它的校验只有一行：
如果后缀在 {.php .jsp .asp .aspx} 里 → 拒绝

也就是说：黑名单 + 只看文件名。 上传后的文件被保存在 static/uploads/， 这是 web 服务器可以直接访问的目录，而且文件名保留你给的原名。
This avatar upload validates exactly one thing: whether the extension is in a short blacklist. Files land in static/uploads/ — directly reachable over HTTP — keeping the name you chose.

通关判定：文件被成功保存，而且它的内容不是图片 （文件头匹配不上任何图片格式）即视为通关。 判定看的是磁盘上真实存在的文件，不是输入里有没有某个词。
Completion rule: the file must be saved AND its content must not be an image (its header matches no image format). The check looks at the file that actually landed on disk.

不用真的做 webshell。新建一个测试文件命名为 note.html，内容随便写点 HTML，上传它试试。
No webshell needed. Create a test file called note.html with some HTML inside and try uploading it.

两个问题：① 校验用的是黑名单，而且只看后缀； ② 文件被存进 web 可直接访问的目录，还用了原名。 前者决定"能不能传进来"，后者决定"传进来之后有多危险"。
Two problems: a blacklist that only inspects the extension, and a web-reachable directory that keeps the original filename. The first decides whether it gets in; the second decides how bad that is.
