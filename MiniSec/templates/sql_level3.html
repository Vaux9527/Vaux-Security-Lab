实验说明 Description

这个会员查询系统和前两关一样，把输入直接拼进了 SQL：
SELECT id, username, password, role FROM union_users WHERE username = '...'

但这一关的数据库里还有第二张表 —— secret_notes， 它是给运维看的内部备忘，前台页面没有任何入口。
The database also contains a second table, secret_notes, an internal note that the front end never exposes.

通关判定：查询结果里出现了 secret_notes 的内容 （也就是那条 flag{...}）即视为通关。 判定看的是「结果里有没有它」，不是「输入里有没有 UNION」—— 前者是事实，后者只是猜测。
Completion rule: the query result must contain data from secret_notes (the flag{...} string). The check is what the query actually returned, not whether your input mentions UNION.

提示：这条查询返回 {{ query_columns }} 列。 UNION 要求拼接的两条 SELECT 列数完全一致， 所以你需要先确认列数，再凑齐它。
Note: this query returns {{ query_columns }} columns. A UNION requires both SELECTs to have the same number of columns, so you need to confirm the count and then match it.
