实验说明 Description

这是一个"网页快照"功能：你把网址填进来，服务器去把页面抓回来给你看。 它校验了协议（只允许 http / https），但没有校验目标是谁。
This is a page-snapshot feature: you supply a URL and the server fetches it for you. The scheme is validated; the destination is not.

通关判定：三个条件同时成立即视为通关 —— ① 请求成功；② 目标地址是内网 / 环回地址 （不是随便抓个外网网页）；③ 响应里出现了内部标记 {{ internal_marker }}。
Completion rule: the request succeeds, the destination is an internal or loopback address, and the response contains the internal marker {{ internal_marker }}.

这台服务器自己就在 127.0.0.1 上跑着，并且暴露了两个内部接口 （/internal/...），它们故意不做登录校验 —— 真实世界的内网服务经常就是这样。
This server listens on 127.0.0.1 and exposes two internal endpoints (/internal/...) with no authentication — exactly like plenty of real internal services.
