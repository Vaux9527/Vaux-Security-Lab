实验说明 Description

这是一个站内搜索。它做了"防护"，但只做了一件很弱的事：
payload = re.sub(r"<script", "", keyword)

也就是说，它只把 <script 这七个字符删掉， 然后把剩下的内容原样拼进 HTML，没有任何输出编码。
This search box does apply a "protection": it strips the seven characters <script, then concatenates the rest into the HTML verbatim, with no output encoding at all.

通关判定：过滤之后真正进入页面的内容里，仍然存在 能被浏览器执行的 HTML 结构（脚本标签、事件属性、可嵌入标签、 javascript: 伪协议之一）即视为通关。 判定看的是"页面里到底变成了什么"，不是"输入里有没有某个关键词"。
Completion rule: after filtering, the content that reaches the page must still contain an executable HTML construct — a script tag, an event attribute, an embeddable tag, or a javascript: URL. The check is what the page ends up containing, not which keywords you typed.

这一关跑在本地，浏览器不会拦住你的脚本 —— 如果注入成功，你会真的看到弹窗。 另外这一关不做任何过滤：它的目的是先让你看清最基本的因果关系。
This lab runs locally and nothing blocks your script: if the injection works, you will actually see the alert. This level also filters nothing, so that the basic cause and effect is unmistakable.
