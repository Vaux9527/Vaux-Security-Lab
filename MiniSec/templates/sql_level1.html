实验说明 Description

本关的后端代码故意使用字符串拼接来构造 SQL 查询： 你的输入会被直接放进 SQL 语句里。 你的任务是让查询条件永远成立，从而一次拿到所有用户。

This level intentionally builds the SQL query with string concatenation, so your input goes straight into the statement. Your goal is to make the condition always true and return every user.

通关判定：一次查询返回的用户数量大于 1 即视为通关。 只把查询对象换成别人（例如 bob' --）同样属于注入， 但本关要求拿到全部用户。
Completion rule: the query must return more than one user. Swapping the target (e.g. bob' --) is also injection, but this level requires every user.
