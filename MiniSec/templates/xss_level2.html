实验说明 Description

这是一个留言板。留言的流程是：
提交 → 原样存进数据库 → 展示时拼进 HTML

过滤器和 Level 1 完全一样（只删 <script）， 展示时也没有做输出编码。
This guestbook stores your message as-is and concatenates it into the HTML when rendering. The filter is the same weak blacklist as Level 1.

通关判定：数据库里存在一条留言，它在经过过滤之后 仍然含有可执行的 HTML 结构，即视为通关。 判定只看"库里现在有没有这样一条留言"。
Completion rule: the database must contain a message that still holds an executable HTML construct after filtering. The check looks at what is stored right now.

和反射型的区别不在绕过手法，而在影响面： 反射型要骗你点一条链接，存储型只需要等你打开页面。
The difference from reflected XSS is not the bypass — it is the blast radius. Reflected needs a click; stored only needs a visitor.
